# Project instructions

- Prefer functional, declarative programming. Keep simulation calculations separate from presentation and platform effects.
- Use typed GDScript. Keep canonical state serializable and scene-independent.
- Include Mermaid diagrams where they explain architecture.
- Check implementation checklists only after verifying the work.
- Commit frequently using conventional commit messages and detailed bulleted descriptions.
- Run `godot --headless --path . --script tests/run.gd` after simulation or mod API changes.
