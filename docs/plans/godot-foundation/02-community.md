# 02 — Playable community

Support a co-op steward managing a courtyard building of five to seven storeys, with configurable footprint, courtyard, materials, households, retail, and individual furnishings. Names, interests, schedules, travel, budgets, and needs make residents inspectable individuals. Model capacity-limited utilities and explicit income/expense transfers. The initial financial-reliability model is implemented; physical capacity and stock inventories remain open. Trace well-being changes to causes.

- [x] Generate a connected courtyard with homes, shops, stairs, and shared space
- [x] Run daily home, work, shopping, rest, and social activities
- [x] Implement furnishing, tenant selection, contributions, and improvements
- [x] Render a warm orthographic world with selectable floors and resident selection
- [x] Make all core flows usable through touch and keyboard/mouse
- [x] Compare forked experiments using equivalent elapsed periods
- [x] Demonstrate a kitchen rule and a garden-village generator without core edits

Benchmarks are sourced; economic tuning is explicitly synthetic. Do not claim scientific validation. Building changes must preserve existing residents and household assignments or be rejected with a reason.

- [ ] Extend utility reliability into physical throughput limits and resource inventories.
